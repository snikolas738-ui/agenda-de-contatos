# Agenda de Contatos

Aplicação de linha de comando desenvolvida em Python para gerenciar contatos, com persistência de dados em banco SQLite.

## Funcionalidades

- Adicionar contato (nome, telefone e e-mail)
- Listar todos os contatos cadastrados
- Buscar contato por nome (ou parte do nome)
- Editar contato existente
- Remover contato
- Persistência automática em banco de dados SQLite (`contatos.db`)

## Tecnologias utilizadas

- Python 3
- SQLite3 (biblioteca padrão do Python)
- Programação orientada a objetos
- Type hints

## Como usar

1. Baixe o arquivo `agenda_contatos.py`
2. Execute no terminal:
3. Use o menu numérico para adicionar, listar, buscar, editar ou remover contatos
4. O banco de dados `contatos.db` é criado automaticamente na primeira execução
